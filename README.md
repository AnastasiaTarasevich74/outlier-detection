# outlier-detection

Статистический анализ одномерной выборки: обнаружение выбросов, проверка нормальности, преобразование Бокса-Кокса.

## Задача

Дана выборка из 1000 наблюдений, взятая из асимметрично распределённой генеральной совокупности. Нужно найти аномальные значения.

## Что сделано

### 1. Описательная статистика и визуализация
- Среднее, медиана, квартили, стандартное отклонение
- Диаграмма рассеяния (scatter)
- Диаграмма размаха (boxplot)

### 2. Поиск выбросов
- **Метод IQR** (межквартильный размах) — `scikit-posthocs`
- **Метод z-значений** с порогом |z| > 5

### 3. Преобразование Бокса-Кокса
- Нормализация асимметричного распределения (`scipy.stats.boxcox`)

### 4. Проверка нормальности
- **Тест Шапиро-Уилка** (`scipy.stats.shapiro`)
- **Тест Андерсона-Дарлинга** (`scipy.stats.anderson`)

### 5. Тесты на выбросы
- **Тест Граббса** (`outlier_utils`)
- **Тест Рознера** — через R (`rpy2` + `EnvStats`)

## Стек

- Python 3: pandas, numpy, scipy, matplotlib, scikit-posthocs, outlier_utils
- R: EnvStats (для теста Рознера)
- Jupyter Notebook / Google Colab

## Результат

Метод IQR выявил 15 возможных выбросов в правой части распределения. После преобразования Бокса-Кокса — 7. Тест Граббса с надёжностью 95% подтвердил минимальное значение (индекс 209) как выброс.
